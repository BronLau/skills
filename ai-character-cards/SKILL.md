# 批量创建 AI 角色卡

目标：在用户确认的人物范围内，生成面容能区分、自然可信的原创人物；每张角色卡的四个视图属于同一个人。

图片理解与角色规划由当前 Codex 完成，生图使用可用的内置 `image_gen` 工具。生图前读取当前环境的 `imagegen` 技能，按其工具调用与文件保存方式执行。默认流程不依赖百炼、Vidu 或自备模型 API Key。

## 提炼与确认

1. 查看本批全部参考图；本地图片通过图片查看工具读取。同一角色卡内的多个视图作为一份人物参考，图片张数不对应生成配额。用户替换参考图时，更新本批来源。
2. 按 [面部设计规则](references/face-design.md) 汇总整批人物的共同方向和变化范围，输出“整体人物方向、8 项面部特征、辅助造型”。依据可见信息区分稳定结构与妆造、光照、修饰效果。
   若本批没有足够清晰的面部信息，说明缺少什么，并请用户补充参考图或文字特征。
3. **上传图片后的回复只输出提炼的特征，并确认是否需要补充修改及生成数量。**不提前展示角色规划、方法解释或生图提示词。已经明确的要求和数量直接沿用；信息缺失时只询问缺少的部分。
4. 用户在此后仅回复数量（例如“6”），表示沿用当前特征并生成该数量，直接继续。已有确认或明确的直接生成指令不重复确认。后续规划以用户最新确认的文本和额外要求替代原图作为依据，确保用户删改生效；原图留作追溯。

## 规划整批角色

数量指独立人物和角色卡的数量。先区分用户确认的人物范围、明确保留项和可以重新设计的面部特征。参考图中的共性不自动成为每个人必须重复的属性；用户明确固定的特征保持不变，在其余维度中形成差异。

先并列比较整批角色的脸部轮廓、下颌、中下庭比例、眉眼关系和鼻唇结构，形成清楚可见的不同组合，再补齐妆造。主要辨识点来自这套整体结构；给相近底脸分别换一个重点部位，仍可能只得到同一类脸的变体。自然协调用于保证结构合理，应保留明确的宽窄、长短和比例差异。

按 [面部设计规则](references/face-design.md) 检查相近组合：如果隐藏名称、发型、服装后，只能用“略长一点、稍宽一点”等微调区分，应先重新规划这些角色的结构组合。允许同一脸型或五官类型重复，判断依据是整体面容；不机械分配脸型或规定差异项数量。需要分批规划时携带已有设定，保持整批对照与编号连续。

人物面部描述按同一 8 项顺序写成连贯中文，使用该人物确定的特征。发型、服装等另行补齐，视觉气质与面部结构协调；角色名称概括“气质＋场景或风格＋人物类型”，以人物定位为主。

保存每个角色的编号、名称、性别、年龄段、简短描述、面部设计要点和完整人物设定。设计要点说明比例、主要辨识点与五官配合，批量时记录相近组合经过调整后的具体结构区别。这些用于内部规划与追溯，不增加用户填写项。

## 组装与生成

将完整人物设定替换进 [四视图提示词模板](references/card-prompt.txt) 的 `{{appearance_prompt}}`，得到每人一条自包含的完整提示词。提交前保存实际文本，校验角色数、连续编号、必要资料和占位符替换。

默认每个角色独立文生图。新角色生成调用只传文字提示词，省略 `referenced_image_paths` 和 `num_last_images_to_include`，不附原始参考图片或其他角色卡。批量生成按角色分别调用内置生图；按实际返回报告分辨率，不把提示词里的尺寸或质量要求当作接口保证。

每张成功结果及时保存到本批输出目录，并在角色资料中记录路径、状态和实际尺寸。中断后先核对已保存结果及仍在运行的任务，再补齐缺项。重新生成一批时使用新版本目录。

## 检查与交付

先并排检查整批实际头肩特写，弱化名称、发型、服装和妆容的影响，判断能否直接从轮廓、五官关系和比例识别不同人物。若仍高度相似、需要反复寻找微小差别，面容差异未通过；不同提示词、不同文件或四视图完整都不能替代这一判断。

对相似组合保留区分较明确的结果，重新设计其余角色未能体现差异的结构，更新个体提示词后再生成并对照。避免不改设定反复抽卡；若继续调整仍未改善，保留结果并如实说明未通过的项目。再分别检查真实感、单卡人物一致性、四视图方位和完整构图，汇报各项实际结果。

发现具体错误时有针对性地调整对应角色；技术失败重试复用已保存的提示词。遇到工具不可用、额度或权限阻塞，保留成功结果并说明缺项，不自行切换外部 API。

交付原图、角色资料与实际提示词，提供完整角色卡和面容对照的本地预览及下载入口。名称、性别和年龄段由预览页面展示，图片内不写文字。此技能交付本地人物资产；写入业务角色库或上架需要另有明确的业务操作请求。

## 修改与可选流程

用户只要求修改规则或提示词文件时，生成新版本并保留旧图与实际提示词的对应关系；不要把草稿提示词标成旧图的生成记录。

用户反馈面孔相似时，优先重做受影响角色的具体结构组合，并核对新旧个体设定的实质差别。公共模板、负向词或妆造的修改单独记录，不能代替面部重新规划。

用户明确选择“先定脸再扩展”时，先生成并确认头像或半身照，再以该已确认形象生成角色卡；遵循 imagegen 的编辑或参考图调用方式。这是需要额外生成与确认的可选流程，普通批量创建直接生成四视图。
