# 面部提炼与设计

提炼输出可编辑的观察范围；规划在用户确认的人物方向内设计独立面孔。观察到的共性与用户明确要求所有人保留的特征分开处理：前者提供参考，后者约束创作。两阶段共用以下 8 项结构，分项完整不等于角色之间已有足够差异。

| 分项 | 关注内容 |
|---|---|
| 1. 脸型与下颌 | 外轮廓、脸部宽长、额头、颧骨、下颌与下巴；可见的中庭、下庭长短及下巴比例。 |
| 2. 眼型与瞳孔 | 眼型、眼尾、眼睑、眼距、眉眼间距、瞳仁视觉表现；区分眼型与眼线、睫毛造成的观感。 |
| 3. 眉形眉色 | 眉形、眉峰、浓淡粗细与眉色；区分骨相和修眉、眉妆。 |
| 4. 鼻型 | 鼻梁的长度、高度、宽度和线条，鼻头与鼻翼；结合整体比例判断。 |
| 5. 唇形唇色 | 嘴唇宽度、唇峰和上下唇厚薄；另说明唇色与妆面润泽。 |
| 6. 肤质与光泽 | 肤色、实际可见纹理、通透度和光泽；分清皮肤细节、光照与柔化修饰。 |
| 7. 面颊与气色 | 面颊、苹果肌饱满度及气色；区分结构和腮红、光影。 |
| 8. 气质、眼神与表情 | 画面呈现的视觉气质、目光和表情，不把观感当作人物真实心理或性格。 |

## 提炼：保留共性和差异

综合比较整批图片，按上述分项概括有效特征。存在长短、宽窄、饱满度等差异时保留范围。图片角度、遮挡、镜头和光照不足以支持判断时，不补造确定特征；面部比例使用可靠的相对描述，无需编造精确数字。

脸型、五官位置和比例是结构依据；眼线、唇色、腮红、皮肤光泽属于表现方式。两类信息在相应分项内说清楚，保持用户可编辑的简洁输出。精修参考中看不清的毛孔，不写成实际观察到的共性。

## 规划：先拉开结构组合，再写完整描述

1. 明确本批的人物范围与固定条件。将未被用户固定的轮廓、骨相、五官关系和比例作为创作空间，允许在参考方向内形成新的自然组合。即使用户固定同一脸型，也应通过其他结构关系形成不同面孔。
2. 先为整批起草简短的面部结构方案，并列比较轮廓宽长、下颌与下巴、中下庭比例、眼型与眼距、眉眼关系、鼻长宽高、唇形与嘴部宽度。根据实际需要选择能形成区分的维度，不规定每人必须有几处差异。
3. 找出结构重叠的组合并重新设计。不能只在相同底脸上更换“圆润眼睛”“修长鼻子”等重点标签；每人的五官和比例应共同建立独立形象。脸型、眼型等类别相同可以成立，但“略长、稍宽”或近义词替换本身不足以证明区分度。
4. 从每套结构中确定主要辨识点，协调其他部位与年龄感、视觉气质。自然协调是结构合理，不是把特征统一弱化到适中；避免失真拼接，也保留清楚、鲜明的个体特征。“一个强项、两个辅助”是取舍思路，不是机械配额。
5. 将这些具体取值按 8 项顺序写成连贯中文。将篇幅优先用于实际形态与关系，共同的摄影和画质要求交给公共模板，避免靠重复审美形容词填充差异。
6. 最后设计妆容、发型、服装和配饰，使其支持人物形象。妆造变化保留已确定的面部结构；肤质、配色或服装的变化不能替代面容差异。

规划对照只验证设定是否充分不同。保存面部设计要点和实际提交的个体描述，便于检查“计划中的差异”是否在图片中落实。面对同质化反馈，要重写实际结构取值或组合，而不只在统一模板后附加“不要相似”。

## 成图：以可直接辨认的面容区别验收

并排查看所有头肩特写，弱化发型、妆容和衣服，先找最相似的组合。轮廓、五官位置与比例的区别应在实际图片中清楚呈现；需要依赖衣服、名字或反复寻找细节才能区分时，标记面容差异未通过。

针对相似组合，识别哪项规划没有落实或差距仍不足，保留合适的结果，重新设计其余角色对应的结构后再生成。修正后与保留角色重新比较；不要只靠换衣服、加皮肤细节或反复重抽同一提示词解决面容相似。

单独检查人物真实感和每张卡的四视图一致性、身体比例、服装延续与完整构图。面容区分、真实感和版式分别判断，某一项合格不能替代其他项；未达到面容目标时如实说明。
