# Omni 原片结构化事实

只观察参考视频中的画面和原始音轨，不做人物替换、产品替换、营销创作或提示词润色。逐镜头核对区间起点、中间和终点。字幕、歌词和营销文案单独作为文字或音频事实，不用于推导肢体动作、表情、景别、运镜或主体进出场。

只输出 JSON：

{
  "schema_version": 2,
  "no_speech_confirmed": false,
  "subjects": [
    {
      "label": "<主要人物>",
      "kind": "character | operator | product | object | scene",
      "original_static_description": "原片直接可见的静态描述"
    }
  ],
  "segments": [
    {
      "index": 1,
      "source_start_seconds": 0,
      "source_end_seconds": 10,
      "duration_seconds": 10,
      "shots": [
        {
          "index": 1,
          "start_seconds": 0,
          "end_seconds": 5,
          "shot_scale": "实际景别",
          "camera": "实际机位、运镜或切镜",
          "composition": "实际构图与主体位置",
          "visible_body_range": "实际可见身体范围",
          "subject_action": "主要人物直接可见的动作",
          "operator_product_action": "操作人员、手部和产品直接可见的动作；没有则明确写无",
          "entry_exit": "实际进出场；没有则明确写无主体进出场",
          "scene_light": "实际场景、背景和光线",
          "beats": [
            {
              "index": 1,
              "start_seconds": 0,
              "end_seconds": 3,
              "action": "该连续阶段中直接可见的人物动作、表情、手部与产品动作"
            }
          ],
          "audio": "<主要人物>（画内、口型同步）说：{逐字台词}；其他画内人物自然闭口聆听。音效：实际音效。没有声音可为空"
        }
      ]
    }
  ]
}

全部时间使用整数秒；分段和镜头必须连续覆盖完整目标时长。每段 `shots` 使用段内相对时间，不使用原片全局时间：第一个镜头的 `start_seconds` 必须为 0，后续镜头首尾连续，最后一个镜头的 `end_seconds` 必须等于该段 `duration_seconds`。每个镜头的 `beats` 也使用段内相对时间，必须从该镜头起点开始、首尾连续并覆盖到镜头终点；同一镜头内出现动作、表情、操作人员或产品动作的阶段变化时，用多个 beat 表达，不得为了阶段变化虚构切镜。`action` 只写该阶段动态事实，不重复景别、机位、构图、场景或声音。

`audio` 使用可直接执行且可机器校验的声音事实。每句台词必须紧邻标注说话人、画内/画外位置和口型状态，只使用 `<说话人>（画内、口型同步）说：{逐字台词}` 或 `<说话人>（画外、无需口型）说：{逐字台词}`。多人依次说话时，每句后写明其他画内人物自然闭口聆听；原片确有同时说话时改为明确的重叠发声。不得只罗列 `{}`台词，不得用引号替代 `{}`。非台词声音分别用 `音效：`、`环境声：`、`音乐：` 标注实际来源，不使用可与主体标签混淆的符号。

存在人声时 `no_speech_confirmed=false`，没有可辨识人声时为 true。主体标签必须使用一对半角尖括号包裹（例如 `<主要人物>`），且全片稳定。
