# Omni 原片结构化事实

只观察参考视频中的画面和原始音轨，不做人物替换、产品替换、营销创作或提示词润色。逐镜头核对区间起点、中间和终点。字幕、歌词和营销文案单独作为文字或音频事实，不用于推导肢体动作、表情、景别、运镜或主体进出场。

只输出 JSON：

{
  "schema_version": 3,
  "overall_av": {
    "visual": "全片共用的表现形式、视觉风格、光影与环境氛围；只写可确认信息",
    "audio": "全片共用的语种、音色、表达方式、配乐与环境声基底；无声时为空"
  },
  "no_speech_confirmed": false,
  "subjects": [
    {
      "label": "<主要人物>",
      "kind": "character | operator | product | object | scene",
      "original_static_description": "原片直接可见的静态描述"
    }
  ],
  "segments": [
    {
      "index": 1,
      "source_start_seconds": 0,
      "source_end_seconds": 10,
      "duration_seconds": 10,
      "shots": [
        {
          "index": 1,
          "start_seconds": 0,
          "end_seconds": 10,
          "shot_scale": "实际景别",
          "camera": "实际机位、运镜或切镜",
          "composition": "实际构图与主体位置",
          "visible_body_range": "实际可见身体范围",
          "subject_action": "主要人物直接可见的动作",
          "operator_product_action": "操作人员、手部和产品直接可见的动作；没有则明确写无",
          "entry_exit": "实际进出场；没有则明确写无主体进出场",
          "scene_light": "实际场景、背景和光线",
          "beats": [
            {
              "index": 1,
              "start_seconds": 0,
              "end_seconds": 10,
              "action": "该连续阶段中直接可见的人物动作、表情、手部与产品动作"
            }
          ],
          "audio": "<主要人物>（画内、口型同步）说：{逐字台词}；其他画内人物自然闭口聆听。<与动作对应的实际音效>"
        }
      ]
    }
  ]
}

分段边界与任务时长使用整数秒；镜头和 beat 使用有限 JSON 数值秒，可含小数，保留真实切镜与动作边界。分段和镜头必须连续覆盖完整目标时长；不要为了凑整秒合并短镜头、增加停顿或重新分配台词。程序只在最终正文中显示近似整秒，JSON 不提前取整。每段 `shots` 使用段内相对时间，不使用原片全局时间：第一个镜头的 `start_seconds` 必须为 0，后续镜头首尾连续，最后一个镜头的 `end_seconds` 必须等于该段 `duration_seconds`。每个镜头的 `beats` 也使用段内相对时间，必须从该镜头起点开始、首尾连续并覆盖到镜头终点；同一镜头内出现动作、表情、操作人员或产品动作的阶段变化时，用多个 beat 表达，不得为了阶段变化虚构切镜。`action` 只写该阶段动态事实，不重复景别、机位、构图、场景或声音。

`audio` 使用可直接执行且可机器校验的声音事实；没有声音时为空字符串。每句台词必须紧邻标注说话人、画内/画外位置和口型状态，只使用 `<说话人>（画内、口型同步）说：{逐字台词}` 或 `<说话人>（画外、无需口型）说：{逐字台词}`。多人依次说话时，每句后写明其他画内人物自然闭口聆听；原片确有同时说话时改为明确的重叠发声。不得只罗列 `{}`台词，不得用引号替代 `{}`。音乐描述完整写在半角 `()` 中，音效与环境声描述完整写在半角 `<>` 中；所有标记成对非空，没有对应声音就省略。全局声音基底集中写入 overall_av.audio，镜头中只写局部声音与变化。同镜头、同声源连续发言合成一对 `{}`，只在真实切镜、换人或明确中断时分组；跨镜发言分别保留实际原文，不重复整句或补全截断话语。

存在人声时 `no_speech_confirmed=false`，没有可辨识人声时为 true。主体标签必须使用一对半角尖括号包裹（例如 `<主要人物>`），且全片稳定。

主体标签是内部引用 ID，其括号内使用唯一、稳定的自然称谓，避免把可替换的品牌、颜色、服装固化到称谓中。后续视觉字段、beat 和说话人统一沿用该 ID。最终正文由程序去掉主体标签的尖括号，使 `<>` 仅承担声音标记。稳定外观集中在 subjects，数量、持有关系和变化状态放在镜头与 beats；同款产品的多个实例不能仅凭外观合并。

overall_av.visual 只描述全片共性，不将局部状态扩大为全片约束；动画、绘画、定格等表现形式据实提取，不预设真实摄影。overall_av.audio 不写台词全文。局部场景、光线和声音变化继续记录在各自镜头中。

默认不把原片的人声转写字幕写入可生成视觉事实。包装、场景标牌、界面及有独立剧情或业务含义的文字按可辨认内容保留在相应视觉字段或 beat，交代载体、位置、样式和持续范围；看不清不补猜。水印、账号标识、批文、认证、免责声明、播放器控件以及这些非剧情前贴的附属缩略图、底板和边框不创建主体、不写入生成事实。过滤仅针对视觉叠加信息，保留真实事件、人声和切镜，不输出过滤说明。
