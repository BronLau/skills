以下规范统一约束本轮生成或改写的视频提示词正文。任务目标、输入处理、内容来源、允许的改写范围、素材选择及外层返回协议由本轮任务规定。返回 JSON 时，本规范作用于视频提示词正文所在字段，不改变其他字段的要求。

## 一、正文结构

严格按以下顺序使用三个固定标题，各独立成行：

主体与场景定义：

按产品、人物、场景的顺序定义视频中需要呈现的核心实体，不存在的类别省略。必要时补充需要独立引用的动物、道具、动作或画面文案。

为实体建立简短、唯一、稳定的自然称谓，后续分镜统一沿用。首次定义可说明编号与称谓的对应，后续不交替使用编号、别称或含糊代词。称谓可依据稳定特征或叙事职责；涉及换装、外观变化或素材替换时，避免将会变化的品牌、颜色、服装等属性固化在称谓中。

集中描述稳定辨识特征：产品的类别、外观与结构，人物的辨识特征与造型基准，场景的空间布局与固定陈设。数量、位置、姿态、持有关系、开闭状态及其他随事件变化的内容写入对应镜头。同款产品可共用外观定义，但各实例的数量与关系分别交代，不仅凭外观相似就认定为同一具体对象。

已有明确的生成参考素材时，将引用及其职责绑定到对应定义，说明采用外观、结构、空间、动作、运镜、音色等哪些属性。沿用实际提供的标签，如 @图片1、@视频1、@音频1。实体称谓与素材标签各自保持一致；多份素材对应同一实体时说明各自作用，不同实体分别绑定。仅用于分析的素材不自动成为生成参考；引用标签必须由本轮任务或实际素材映射提供，不编造编号。

整体视听设定：

描述全片共用的表现形式、视觉风格、光影、环境氛围，以及语种、音色、表达方式、配乐与环境声基底，不重复实体定义，也不集中输出对白、旁白或歌词全文。局部变化写入对应分镜。

分镜与声音：

按本轮任务确定的镜头顺序展开。每个镜头先写规定的标题，再用自然语言交代主体与场景、开始画面、动作与状态变化、构图运镜、有效画面文字、结束状态及转场，随后交代对应声音。依据实际内容取舍，不套固定字段表或补空项。

以具体的动作、接触位置、物体归属和空间关系表达事件，分清主体运动与摄影机运动。相邻镜头的动作进程与状态应能衔接，未完成的动作或话语按本轮确定的结束状态表达。一致性要求融入实体定义与具体镜头，不将局部状态扩大为全片不变。

## 二、镜头标题与时间

每个镜头以独立标题行开始，统一格式为：

镜头N｜MM:SS - MM:SS

N 从 1 连续递增；MM 表示分钟，SS 表示秒，均补足两位数字；起止时间之间使用半角连字符，两侧各留一个空格。使用整秒，不使用小时、毫秒或小数秒。镜头之间空一行。镜头内另行标注的声音或文字时间同样使用 MM:SS - MM:SS。

时间轴依据本轮任务确定，全文使用同一时间基准，覆盖要求的视频范围与结尾。整秒标签用于近似表达，不作为精确素材定位。不为凑整秒或容纳完整台词而改变已确定的镜头边界、合并短镜头、增加停顿或重新分配内容。

不足一秒的连续短镜头可共享同一整秒区间，以编号明确先后；共享区间不表示叠化。转场按实际需要表达。片尾可向上取整以覆盖结尾，但不据此增加画面或声音时长。

## 三、声音组织与标记

声音内容与人声文案由本轮任务确定。全片共性放在整体视听设定，具体发言、局部音效、音乐变化及有意义的静默放在所属镜头，不为补齐格式增加声音。

整体视听设定可用自然语言概述声音，不强制使用标记。分镜与声音中的声音描述和字幕原文必须按以下用途完整写在对应符号内部：

- 音乐使用半角 `()`，如 `(轻柔钢琴配乐持续铺底，片尾逐渐减弱)`。
- 音效与环境声使用半角 `<>`，如 `<杯底接触木桌的轻响>`、`<持续的雨声>`。
- 人声文案使用半角 `{}`，包括对白、旁白、画外解说、内心独白和歌词。说话人、画内或画外发声方式、语气、动作和时间说明放在符号外，如“画外女声轻声说：{等一下。}”。
- 用户明确要求添加或保留字幕时，字幕原文使用 `〖〗`，位置、样式和出现时间写在符号外。

每组标记须配对、非空、用途正确，完整包裹对应内容，不以空符号作为类型前缀，也不将应包裹的内容写在符号外。符号仅用于区分内容，不是需要生成到画面中的字符；文案自身的字符仍按原文保留。示例只说明格式，不要求新增示例内容。

每个有发言的镜头写出该镜头对应的具体文案，明确声源及画内外属性，不以“台词继续”“口播延续”或“口型同步”代替原文。保持本轮确定的声源关系，不因人物出镜就将旁白改成该人物的画内发声。

同一镜头、同一声源的连续发言写在同一对 `{}` 中；字幕换行、标点和短暂停顿不拆组。真实切镜、换人或明确中断时分组。跨镜发言分别写出各镜头承载的文案与承接关系，保持顺序及发声时序，不因分组重复整句、补全截断话语或增加停顿。

音乐与环境声的共性可沿用整体设定，不必逐镜重复；在分镜中写出时仍须使用对应标记。声音起止与镜头边界不同且影响声画关系时，在镜头内另行标注其时间，不另建镜头编号。

## 四、字幕与画面文字

默认在整体视听设定中明确写入“全片不生成字幕”。用户明确要求添加或保留字幕时，改为对应设置。

默认不复现输入视频中的对白字幕、翻译字幕、歌词字幕或解说字幕，也不将其改称剧情字卡或业务文案继续输出。无字幕规则只作用于画面文字，不删减本轮需要保留的人声内容。

实物包装、场景标牌、界面文字，以及具有独立剧情或业务含义的标题、字卡等，根据本轮任务表达；不将无字幕扩大为画面不能出现任何文字。需要呈现的文字说明内容、载体或位置、样式、出现方式与持续范围。基于素材保留文字时，看不清的字只描述可确认的文字区域与排布，不补猜具体词句。场景内文字使用自然语言说明物理载体，不套用字幕标记。

水印、平台或账号标识，以及药品或保健品批文、注册号、广告批准文号、认证标识、免责声明等非剧情前贴图文，不进入正文；同一前贴区域的附属产品缩略图、底板、边框等一并排除，不据此创建主体或补充实体属性。播放器控件不作为视频内容。

上述过滤覆盖主体定义、整体设定和全部分镜，不将被排除的信息转写为其他视觉元素，也不附忽略清单或去除水印等编辑指令。保留其下本轮需要表达的真实事件，不因过滤叠加信息删改声音或镜头关系。

## 五、正文表达与完整性

直接写成指导视频生成的创作指令，以具体实体、动作、空间和视听变化表达内容。正文内不附分析过程、解释、评分、备选方案或格式说明，不使用 Markdown 代码围栏。

共性集中定义，各镜头重点写变化。素材引用不能代替事件、镜头及声音组织；简单视频保持紧凑，复杂视频按内容展开，明确发生什么、如何推进以及如何结束。

仅在本轮任务明确要求输出可编辑模版时，按该任务规定使用业务占位符；其他情况下填写完整实际内容，不遗留空字段或待填说明。占位符的定义、登记与替换方式由对应任务负责。

输出前在内部核对：三个标题及顺序、称谓与引用对应、镜头时间格式与覆盖范围、状态衔接、逐镜人声归属与分组、分镜标记完整性，以及字幕与前贴过滤是否符合上述规则。检查过程不写入正文。
