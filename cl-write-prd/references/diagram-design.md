# 飞书原生画板设计规范

本文件统一维护 PRD 画板的信息组织、视觉设计和原生交付规则。是否需要画图按 [prd-style.md](prd-style.md) 判断；创建或调整画板时读取本文件，具体读写命令使用当前 `lark-whiteboard` Skill。

交付物是可编辑的飞书原生形状、文字和连接器，保留节点间的连接关系。设计原则已在本文件中完成适配，无需安装上游 Skill，也不采用 HTML、SVG 或整图图片作为画板交付物；预览图片仅用于检查。

## 信息组织与图型

- 一张图回答一个核心问题。每个节点表达一个动作、判断或状态，名称简短；参数、限制和详细交互放在相关正文，不把整段说明塞进框里。
- 按关系选图型：分支判断用流程图，跨角色交接用泳道图，状态变化用状态图。主链路、关键条件、输入输出与返回关系应可追踪。
- 合并不改变业务含义的重复节点和装饰性元素。时序、因果、并行关系及必要分支不能因为版面拥挤而省略。
- 约 9 个节点或 12 条连线是拆图提醒，不是删减需求的硬上限。复杂内容优先组织为总览与局部详图，标清子流程名称、入口和出口；不通过缩小文字把全部细节挤入一图。

## 布局、节点与字体

- 主流程保持统一阅读方向，同层节点对齐，同类节点使用一致的尺寸、间距和内边距。先安排节点和走线空间，再补充标签；采用统一间距档位，无需机械套用 SVG 的像素栅格。
- 形状表达语义：起止用圆角或椭圆，动作用矩形，判断用菱形，汇合关系明确呈现。判断的每个出口都标明条件，出口过多时分层组织判断。
- 泳道只在需要区分参与者或职责时使用，每条泳道有名称，每个动作有明确归属。分区用标题、留白或轻量分隔表达，避免多层大面积彩色容器。
- 使用飞书可用的中文无衬线字体。节点名称适度加重，补充说明和连线标签用常规字重；等宽字体仅用于代码、字段等技术标识。
- 按中文实际字宽与文档显示比例安排文字空间，不照搬英文小字号。放不下时先精简表达、扩框或拆图，保持文字、边框和连线之间的留白。

## 视觉层级与配色

先让读者看到关键节点和标题，再沿连线阅读。默认使用干净浅底、细边框、适度圆角；省略阴影、发光、纹理和无业务含义的装饰。

| 角色 | 默认处理 |
| --- | --- |
| 画布与普通节点底色 | 不透明白色 `#FFFFFF`，需要区分容器时使用极浅的中性色 |
| 主要文字 | 深色 `#1F2329` |
| 补充文字与常规连线 | 中性灰 `#646A73`，保证与实际底色的对比 |
| 节点边框与分隔 | 中性细线，强调层级依靠布局和文字，不靠整片色块 |
| 重点 | 每图突出 1～2 处，沿用已确认的项目主色；未给出主色时使用中性配色 |

- 固定图内配色，不继承作者的阅读器主题。文字与所在背景成对设置；深色强调节点使用浅色字时，同时固定深色底。
- 连线与箭头的视觉权重低于节点和标题。主路径与返回路径均使用细线、小型开放箭头；缩放后难辨时先调整布局、展示尺寸和对比度，不整体加粗。
- 图例仅在符号或线型含义需要解释时添加，放在主图之外或底部。

## 连线与标签

- 同轴节点直接连接；错位节点优先使用圆角正交折线，避开斜穿节点和长距离来回绕行。连线从节点边缘垂直进出，避开角点。
- 每条路径独立可追踪。平行连线分开，同一节点边上的多条连线使用不同连接点；优先通过调整布局消除交叉，确实需要交叉时使用工具支持的跨线标识。
- 连线绕开非起止节点，不用被节点遮住的路径暗示关系。虚线可表达返回、可选或异步关系，同一图中含义一致。
- 标签使用简短条件或动作，保持横排，位于连线上方或旁边并留出可见间隙。标签底色与所在背景协调，不遮断连线，不碰节点边框，也不被其他节点覆盖。

## 飞书原生实现

- 使用 `lark-whiteboard` 的 DSL → OpenAPI 原生节点路线；本文件的原生交付要求优先于通用绘图 Skill 的 SVG 路由。具体参数以当前工具为准。
- 原生连接器的起止端应绑定实际节点，保留节点标识与连接关系；不要用无绑定的普通线段或整图图片代替流程连接器。需要共同编辑的形状和文字按工具能力组织。
- 完成布局与路由后，以全部节点、完整连线路径、箭头和标签的外接范围确定背景，并留出边距。背景置底，连线位于节点下方，标签置于空白处；外绕和折返路径也须落在背景内。
- 首次写入前检查转换结果。固定文字颜色需同时设置 `text_color` 和自定义类型 `text_color_type: 1`；仅有色值、仍使用主题类型 `0` 不视为已固定。除节点 `text` 外，特别检查 `connector.captions.data`；填充和描边同样固定颜色类型与不透明度。
- 连线默认从 DSL `lineWidth: 2` 起，检查原生 `style.border_width` 为细线档 `"narrow"`，开放箭头为 `"line_arrow"`。不能只凭源文件参数判断最终粗细；按文档实际显示比例复核。
- 转换丢失样式时，在写入前补齐颜色和线宽属性，保持标识、绑定和几何关系。工具无法保留标签配色或留距时，可用独立原生文字与底色节点呈现标签，并移除重复的连接器文字；连接器本身仍绑定起止节点。

## 检查与交付

在本次授权范围内完成检查，发现问题先修正相应图形，不以增加文字说明掩盖绘图问题。

- **语义：** 主链路、必要分支、并行与返回关系完整，拆图后的入口、出口和引用一致。
- **视觉：** 信息不过密、重点明确、文字有留白；连线和标签互不遮挡，两侧绕线可追踪，背景覆盖完整。
- **可编辑性：** 回读包含原生形状、文字和连接器，连接器绑定有效，颜色类型和细线档保留；一张预览图不能证明可编辑性。
- **实际显示：** 在文档内常规显示尺寸检查字号、箭头和连线，确认既清晰又不抢过节点。有独立预览能力时检查深浅两种模式；无法完成时说明已验证范围，不把本地预览等同于飞书显示验证。
