# 飞书文档编辑规则

## 前置

- 完整阅读 `lark-doc` 与 `lark-shared` Skill。
- 所有 `docs +fetch`、`docs +create` 和 `docs +update` 操作携带 `--api-version v2`。
- 编辑前使用完整详细度读取目标文档，保留 block ID 和样式信息。

## 读取

- 目标文档只有标题时读取整篇。
- 已有较多内容时先读取目录，再按章节局部读取。
- 同时读取风格范本文档最新版本；无法读取时使用本 Skill 的 `prd-style.md`。

## 写入

- 精准编辑优先使用 XML 和 block 级更新。
- 新增内容插入到正确标题或相邻 block 后。
- 替换内容仅替换用户确认的 block。
- 保留已有图片、附件、画板、表格、网格、引用和待办复选框。
- 禁止为省事使用整篇 overwrite。
- 用户明确要求编写某个章节时，该指令即为写入授权，直接进行块级编辑，不重复确认。
- 仅在用户要求先预览、目标文档只有标题且大纲尚未确认，或已有正文的替换与删除范围不明确时，先在对话中展示拟写内容并等待确认。
- 用户明确要求直接写或直接修改时，在其授权范围内跳过预览。

## 飞书组件

- 业务流程使用飞书画板原生节点；不要生成 SVG。
- 流程图下补充“步骤说明”和有序列表。
- 页面设计需要截图时插入文本占位，不插入本地图片。
- 字段枚举或参数对照使用表格。
- 并列文件或 Prompt 模块可按实际需要使用网格与文件卡片。
- 验收标准按能力模块使用三级标题分组，各组使用文档待办复选框，不使用飞书任务。

## 校验

写入后重新读取目标章节完成结构和内容校验。XML 回读不包含真实页面换行，因此还需在飞书可见页面以常规文档宽度检查本次写入范围，扫描全部段落、列表项和待办项，并一次处理发现的全部短尾行。无法查看可见页面时，按 `prd-style.md` 压缩文案，并明确说明尚未完成可视版式校验。

检查：

- block 是否位于正确章节；
- 标题层级和编号是否连续；
- 是否保留原有媒体和富文本组件；
- 是否出现重复、遗漏或错误替换；
- 文案是否符合风格范本；
- 截图占位和待办复选框是否使用正确组件。

发现写入失败、权限不足或文档版本冲突时停止后续写入，保留已成功内容并向用户说明具体问题。
