# 页面截图占位

## 标准格式

在页面截图应出现的位置写：

```xml
<p><span text-color="yellow">截图内容描述：&lt;页面入口、前置状态、触发操作、关键组件和建议截图范围&gt;。</span></p>
<p align="center"><span text-color="gray">「&lt;截图名称&gt;」</span></p>
<ul>
  <li>&lt;新增或变化的交互规则&gt;</li>
  <li>&lt;系统行为或业务结果&gt;</li>
</ul>
```

## 编写要求

- 以“截图内容描述：”开头。
- 将“截图内容描述”占位段落的全部文字设为黄色。
- 将截图名称所在段落居中，并将整行文字设为灰色；下方交互说明保持正文默认颜色。
- 写明用户如何进入目标页面或弹窗。
- 写明截图前必须完成的操作和页面状态。
- 写明需要触发的点击、右键、上传、生成或切换操作。
- 列出截图中必须出现的关键组件、状态和文案。
- 页面范围较大时说明建议截取的区域。
- 一张截图承载一个主要页面或交互状态。

## 边界

- 不自动操作原型页面。
- 不自动生成、截取或上传图片。
- 不用模拟图或 SVG 替代真实原型截图。
- 不声称图片已经插入。
- 用户手动截图后，仅替换“截图内容描述”文本，保留截图名称和下方说明。
