# 页面截图与占位

## 自动截图

- 默认使用当前会话已确认的原型 URL 或本地 HTML，优先复用对应浏览器标签页。用户明确指定现有图片或手动配图时遵循其选择；已有准确截图可直接保留。
- 检查当前会话可调用的浏览器操作与截图能力，获取可用于飞书上传的图片文件。仅能打开链接或读取 HTML 源码，不等于具备截图能力。
- 根据本节要说明的核心交互，使用原型已有演示数据进入目标页面、弹窗或状态，等待内容加载稳定。一张截图表达一个主要状态：页面截图以应用内容边界取景，弹窗或局部交互优先截对应组件，并保留少量必要上下文。
- 优先使用浏览器支持的元素或区域截图；整视口截图须检查内容边界，按实际画面裁去无关的外边缘留白或浏览器区域。裁切只改变取景范围，保留完整控件、文案与原有比例；范围按本次图像确定。
- 保存后查看最终将上传的图片，确认状态、文案与最终需求一致，关键组件完整、文字清晰，四边没有无关空白带。发现取景问题先重选范围、重截或裁切并复查，再上传；不通过修改原型布局消除截图留白。若页面尚未实现目标状态，保留占位并说明差异。
- 按 `lark-editing.md` 将图片插入对应页面标题下、截图名称前；保持图片比例，图名使用居中灰色文字，交互说明使用正文默认样式。
- 回读确认图片块及其资源引用位于目标章节；具备文档浏览能力时再检查显示效果。已有占位仅在图片就位后移除，保留图名和仍有效的说明。

## 无法自动完成时

浏览器未接入、原型不可访问、状态无法复现、截图不合格，或图片写入未完成时，保留已完成内容并使用下方占位。明确失败可在修正原因后重试一次；写入结果不确定时先回读，复用已成功的图片块，不重复上传。仍未完成则说明具体环节和原因，继续可完成的正文工作；文档权限或版本冲突按 `lark-editing.md` 停止写入。

用户明确要求手动配图时也使用占位。仅获取到本地截图或上传成功，尚不足以报告“已插入文档”。

## 占位格式

在待配图位置写以下 XML；这里只设置文字颜色，不使用黄色背景：

```xml
<p><span text-color="yellow">截图内容描述：&lt;页面入口、前置状态、触发操作、关键组件和建议截图范围&gt;。</span></p>
<p align="center"><span text-color="gray">「&lt;截图名称&gt;」</span></p>
```

图名后仅在有必要补充时添加交互说明，内容取舍按 `prd-style.md`；不因占位格式而强制生成规则列表。

## 占位说明

- 以“截图内容描述：”开头。
- 将“截图内容描述”占位段落的全部文字设为黄色。
- 将截图名称所在段落居中，并将整行文字设为灰色；下方交互说明保持正文默认颜色。
- 用简短描述写清入口、必要前置状态、触发操作、关键组件和截图范围，足以让用户独立复现。
- 后续补图替换占位，保留截图名称及仍有效的说明；截图使用实际原型，不以生成图或 SVG 代替。
